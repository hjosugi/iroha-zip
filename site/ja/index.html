iroha-zipは、libarchiveを一時AppContainerに隔離し、展開前後と圧縮元をRust側で検査するWindows用アーカイブラッパーです。

境界を分けて、
公開前に検査。

未信頼の書庫を通常ユーザー権限のまま直接展開しません。バックエンド、作業領域、最終出力の境界を分け、どこか一つが壊れても暗黙に処理を続けない設計です。

  1. 1. 固定bsdtar一式をSHA-256マニフェストで完全照合
  2. 2. 隔離capabilityなし・ネットワークなしの一時AppContainer
  3. 3. 監視時間、メモリ、プロセス数、ファイル数、展開容量を制限
  4. 4. 再検査パス、リンク、ADS、予約名、identity、内容を監査
  5. 5. 公開検査済みの通常ファイルだけを新規フォルダへatomic publish
A

fail closed

AppContainer作成、ハッシュ検証、監査、cleanupのいずれかが失敗すれば、通常権限へ降格せず停止します。

B

作成も隔離

圧縮元を監査・複製し、生成書庫を別sandboxで再展開。元treeと一致するまで公開しません。

C

由来を固定

backend manifest、provenance、SPDX SBOM、license evidenceの完全一致を検証できます。

3ステップで導入。

通常は配布ZIPを選びます。バックエンドを意図的に分離しているため、初回だけ自分が信頼するlibarchiveを取り込んでください。

01

ダウンロード

最新ReleaseからPCに合うWindows x64／ARM64 ZIPを取得し、任意の新規フォルダへ展開します。

02

ハッシュ確認

SHA256SUMS.txtとGet-FileHashの値を比較します。必要に応じてGitHub attestationも確認します。

03

バックエンド設定

iroha-zip.exe settingsを開き、MSYS2または信頼済みbundleを取り込み、診断を実行します。

ハッシュを確認

Get-FileHash `
  .\iroha-zip-0.6.1-windows-x64.zip `
  -Algorithm SHA256

設定と診断

.\iroha-zip.exe settings
.\iroha-zip.exe doctor

日本の古い書庫も。

libarchiveが有効にしている形式を自動判定します。UTF-8 process modeで新しい日本語名を保ち、文字コード情報のない古い日本語ZIP/LZHにはCP932を明示できます。単体GZ/BZ2/XZ/Zstandard/.Zは、外側の拡張子を外した安全な1 fileへ、事前検査と実展開を別AppContainerで行います。

展開ZIP / ZIPX、7z、RAR / RAR5、LHA / LZH、TAR、GZ、BZ2、XZ、Zstandard、.Z、CABほか
作成ZIP、7z、TAR、TAR.GZ
文字コードauto、UTF-8、CP932、CP437
対象OSWindows 10 version 1903以降。x64／native ARM64を配布し、ARM64自動証拠はWindows 11 ARM
実行runtime対象architectureのMicrosoft Visual C++ v14 Redistributable。VCRUNTIME140.dll不足時は公式packageを導入し、第三者DLL配布siteを使用しない
 
iroha-zip.exe extract .\old-japanese.zip --encoding cp932
iroha-zip.exe create seven-zip .\folder .\folder.7z

拒否するものを明確に。

便利さのために危険な構造を黙って正規化しません。監査結果が曖昧な場合は出力を公開せず、partial treeをcleanupします。

主な拒否条件

  • ..、絶対／drive／UNC path
  • symlink、junction、reparse point、hard link
  • NTFS Alternate Data Stream
  • 重複memberと大小文字／separator alias
  • Windows予約名、末尾ドット／スペース
  • 設定した容量、個数、深さ、長さの超過
  • 既存出力の上書き

確認可能な証拠

  • 脅威モデル
  • Windows E2E契約
  • 悪性書庫コーパス
  • 暗号化書庫の境界
  • バックエンド証跡
  • Security policy

ダブルクリックも、CLIも。

設定画面から関連付け候補を登録できます。CLIではpreview、選択展開、作成、診断を同じpolicy境界で利用できます。

展開・プレビュー

iroha-zip.exe preview .\archive.zip
iroha-zip.exe extract .\archive.zip
iroha-zip.exe extract .\encrypted.zip `
  --prompt-password
iroha-zip.exe extract .\archive.zip `
  --select "資料\index.txt"

作成

iroha-zip.exe create zip `
  .\folder .\folder.zip

iroha-zip.exe create tar-gz `
  .\folder .\folder.tar.gz
